pub fn into_server( self, ) -> Server<Arc<Self>, Registered<Arc<Self>>, NotRegistered, NotRegistered, NotRegistered>
where Self: Send + Sync + 'static,

Convert this handler into a fully-configured MCP server.

This method automatically registers all handlers defined on this type via #[tool], #[resource], and #[prompt] attributes.

The handler is wrapped in Arc internally, so there’s no need to implement Clone on your handler type.

§Example
ⓘ
let server = MyServer::new().into_server();
server.serve(transport).await?;
